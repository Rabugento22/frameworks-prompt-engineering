# Código de Conduta

## Objetivo

Este repositório foi desenvolvido como parte de uma atividade acadêmica da disciplina de Inteligência Artificial, com foco na aplicação prática de frameworks de Prompt Engineering.

O objetivo deste Código de Conduta é estabelecer princípios básicos para colaboração, respeito e compartilhamento de conhecimento.

---

# Princípios

Todos os participantes são incentivados a:

- Agir com respeito e cordialidade.
- Compartilhar conhecimento de forma colaborativa.
- Aceitar críticas construtivas.
- Manter um ambiente acolhedor para aprendizagem.
- Valorizar diferentes opiniões e experiências.

---

# Comportamentos Esperados

São considerados comportamentos positivos:

- Utilizar linguagem respeitosa.
- Compartilhar boas práticas.
- Contribuir com sugestões de melhoria.
- Reportar problemas de forma objetiva.
- Colaborar com a evolução da documentação.

---

# Comportamentos Inaceitáveis

Não são aceitos:

- Linguagem ofensiva ou discriminatória.
- Assédio de qualquer natureza.
- Divulgação de informações sensíveis.
- Conteúdo ofensivo ou inadequado.
- Ataques pessoais.

---

# Escopo

Este Código de Conduta aplica-se a:

- Issues
- Pull Requests
- Discussões
- Comentários
- Toda a documentação presente neste repositório

---

# Comunicação

Caso seja identificada alguma conduta inadequada, recomenda-se comunicar o mantenedor do projeto para avaliação e tratamento da situação.

---

# Referências

Este documento foi inspirado no Contributor Covenant e adaptado para fins acadêmicos e educacionais.

---

# 💡 Sugestões de Melhoria

Em futuras versões deste projeto, este documento poderá evoluir com:

- Processo formal para reporte de incidentes.
- Fluxo de mediação de conflitos.
- Política de privacidade.
- Política de segurança.
- Guia de divulgação responsável de vulnerabilidades.

Essas melhorias aproximariam o repositório dos padrões adotados por projetos open source de grande porte.
