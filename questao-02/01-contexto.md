# Contexto da Questão 02

## Cenário

A Hill Valley Tech possui aplicações críticas responsáveis pelo processamento de informações financeiras.

Entre essas aplicações encontra-se o sistema **Ledger**, cujo banco PostgreSQL necessita de backups periódicos para garantir a continuidade dos serviços e a recuperação em caso de incidentes.

Como parte da estratégia de confiabilidade da infraestrutura, tornou-se necessário automatizar todo o processo de backup.

---

# Problema

A solução deveria contemplar:

- execução automatizada;
- armazenamento em Amazon S3;
- logs detalhados;
- tratamento explícito de erros;
- execução segura;
- organização do código;
- compatibilidade com cron.

---

# Objetivo

Construir um prompt capaz de orientar um Modelo de Linguagem na geração de um script Bash pronto para produção.

---

# Competências Desenvolvidas

Durante esta atividade foram aplicados conhecimentos relacionados a:

- Linux;
- Bash Script;
- PostgreSQL;
- Amazon S3;
- AWS CLI;
- Prompt Engineering;
- Site Reliability Engineering (SRE);
- Automação de Infraestrutura;
- Observabilidade.

---

# Relação com o Framework

O framework R-T-F mostrou-se adequado para este cenário por permitir definir claramente:

- quem executará a tarefa;
- qual tarefa deverá ser realizada;
- como a resposta deverá ser apresentada.

Essa organização favoreceu a geração de um script consistente e aderente aos requisitos definidos no desafio.
