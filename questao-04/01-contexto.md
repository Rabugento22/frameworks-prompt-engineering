# Contexto da Questão 04

## Cenário

O sistema **Ledger** registra diariamente milhares de transações financeiras realizadas pelos clientes da Hill Valley Tech.

Para apoiar a tomada de decisão da área de Produto, tornou-se necessário gerar um relatório consolidado contendo indicadores mensais sobre o volume financeiro movimentado em cada categoria de transação.

Essas informações servem como base para análises de crescimento, comportamento dos clientes e planejamento estratégico. :contentReference[oaicite:2]{index=2}

---

# Problema

A consulta SQL deveria atender simultaneamente diversos requisitos funcionais:

- considerar apenas transações concluídas;
- aplicar corretamente o recorte temporal;
- agrupar por mês e categoria;
- converter valores de centavos para reais;
- calcular quantidade e volume financeiro;
- apresentar os dados em formato adequado para consumo pela área de Produto.

---

# Objetivo

Construir um prompt capaz de orientar um Modelo de Linguagem na geração de uma consulta SQL pronta para utilização em ambiente de produção.

---

# Competências Desenvolvidas

Durante esta atividade foram aplicados conhecimentos relacionados a:

- PostgreSQL;
- SQL Analítico;
- Engenharia de Prompt;
- Modelagem de Dados;
- Agregações;
- Manipulação de Datas;
- Relatórios Gerenciais;
- Regras de Negócio.

---

# Relação com o Framework

O framework **T-A-G** permitiu organizar a atividade em uma sequência lógica de execução, reduzindo ambiguidades e aumentando a qualidade da consulta produzida pelo modelo.
