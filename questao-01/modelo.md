# Modelo de IA Utilizado

## Questão 01

### Modelo

**GPT-4o**

---

# Objetivo da Escolha

Nesta questão foi necessário gerar um **Dockerfile para uma aplicação Flask**, seguindo boas práticas de conteinerização voltadas para ambientes de produção.

A tarefa exigia que o modelo fosse capaz de:

- compreender conceitos de Docker;
- conhecer boas práticas de DevOps;
- produzir código corretamente formatado;
- explicar as decisões adotadas durante a construção da solução.

Por essas características, foi selecionado o **GPT-4o**, que apresenta excelente desempenho em geração de código e documentação técnica.

---

# Características do Modelo

Durante o desenvolvimento deste projeto, o GPT-4o demonstrou boa capacidade para:

- geração de código;
- criação de Dockerfiles;
- Kubernetes;
- Shell Script;
- YAML;
- Python;
- documentação técnica;
- explicações estruturadas.

Além disso, respondeu de forma consistente a prompts organizados utilizando frameworks de Prompt Engineering.

---

# Motivos da Escolha

A seleção do modelo considerou principalmente:

## Capacidade Técnica

O GPT-4o possui amplo conhecimento sobre tecnologias relacionadas a:

- Docker;
- Flask;
- Python;
- Containers;
- Linux;
- DevOps.

---

## Organização das Respostas

O modelo apresentou respostas bem estruturadas, com:

- separação lógica entre etapas;
- utilização correta de blocos de código;
- comentários explicativos;
- boa legibilidade.

---

## Aderência ao Prompt

O modelo seguiu corretamente todas as instruções fornecidas pelo framework **R-T-F**, respeitando:

- papel definido;
- tarefa solicitada;
- formato esperado.

Essa aderência reduziu significativamente a necessidade de refinamento do prompt.

---

# Pontos Fortes Observados

Durante esta atividade foram identificadas as seguintes características positivas:

- excelente geração de código;
- boa organização lógica;
- facilidade para documentação técnica;
- compreensão de boas práticas de Docker;
- respostas objetivas;
- boa qualidade na explicação do código produzido.

---

# Limitações Observadas

Embora o desempenho tenha sido bastante satisfatório, alguns aspectos merecem atenção.

Em cenários corporativos seria recomendável revisar manualmente itens como:

- versões das imagens utilizadas;
- políticas de segurança;
- execução com usuário não privilegiado;
- otimizações específicas para redução do tamanho da imagem;
- requisitos internos da organização.

Essas verificações fazem parte do processo normal de revisão técnica e não representam falhas do modelo.

# Conclusão

A escolha do GPT-4o mostrou-se adequada para esta questão, pois o modelo apresentou boa compreensão do contexto, aderência ao framework R-T-F e capacidade de produzir um Dockerfile organizado e alinhado às boas práticas de conteinerização.

Sua utilização contribuiu para reduzir ambiguidades e gerar uma resposta consistente, reforçando a importância da escolha do modelo de IA em conjunto com a definição de um framework de Prompt Engineering apropriado.
